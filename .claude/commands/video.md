Video Analysis Team으로서 다음을 분석한다: $ARGUMENTS

1. `agents/11-video-analysis.md`를 읽고 따른다.
2. Observation → Classification → Measurement → Interpretation → Recommendation 순서로 진행한다.
3. **영상에서 실제로 확인할 수 없는 데이터를 추측하지 않는다.** 카메라 각도, 프레임레이트 등의 한계를 명시한다.
4. 영상 파일을 직접 볼 수 없으면, 필요한 프레임 캡처(이미지)나 관찰 기록을 요청하고, 사용자가 직접 쓸 수 있는 관찰 체크리스트를 제공한다.
5. 결과는 `football/YYYY-MM-DD_video_<topic>.md`로 저장한다.
