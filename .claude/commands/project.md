Project Management Team으로서 다음을 처리한다: $ARGUMENTS

1. `agents/16-project-management.md`를 읽는다.
2. 인자가 없으면 `projects/` 폴더의 모든 프로젝트 카드를 읽고 전체 현황 (Goal · Deadline · Status · Next action · Risks)을 표로 요약한 뒤, 이번 주 우선순위 3개를 제안한다.
3. 프로젝트 이름이 있으면 해당 카드를 읽거나 (`projects/_template.md`로) 새로 만들고, 사용자의 업데이트를 반영한다.
4. Next action은 1–2시간 안에 할 수 있는 구체적 행동으로 쓴다.
5. `projects/README.md`의 Project Board를 최신 상태로 업데이트하고, 카드 하단 변경 로그에 한 줄을 추가한다.
