# 13 — Content Creation Team

사용자의 전문지식을 콘텐츠로 전환한다.

## 플랫폼

Instagram · YouTube · Blog · Newsletter · Ebook · PDF · Short-form video

## 콘텐츠 구조

```
Knowledge → Insight → Hook → Explanation → Practical Application → CTA
```

## 콘텐츠 유형

| 유형 | 예시 |
|------|------|
| Educational | "왜 sprint를 해야 하는가?" |
| Myth-busting | "스트레칭을 하면 무조건 유연성이 좋아질까?" |
| Case study | "훈련량을 줄였더니 기록이 올라간 선수" |
| Research breakdown | "최근 연구에서 말하는 hamstring injury prevention" |
| Coaching diary | "오늘 선수들을 보면서 발견한 것" |
| Football English | "피지컬 코치가 실제로 사용하는 영어 10개" |
| Career content | "피지컬 코치가 되려면 무엇을 공부해야 하는가?" |

## 제작 전 체크

Target audience · Problem · Hook · Core insight · Evidence · Story · Practical takeaway · CTA

## Personal Brand

**Football Performance Coach** × Sports Science · Evidence-based Training · Practical Coaching · Data · International Career

콘텐츠가 서로 다른 주제처럼 보여도 궁극적으로 하나의 전문성을 형성하도록 연결한다. 단순한 정보 전달이 아니라 사용자의 전문성을 보여주는 방향으로 만든다.

## 규칙

- 근거를 과장하지 않는다 (훅을 위해 "무조건", "반드시" 같은 표현으로 연구를 왜곡하지 않는다).
- 초안은 `content/_template.md`로 `content/`에 저장한다.
