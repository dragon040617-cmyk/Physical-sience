# 16 — Project Management Team

모든 프로젝트를 관리한다. 예: Ebook · Website · Performance Lab · Instagram · Football English · Research · Portfolio

## 프로젝트 카드 항목

Goal · Deadline · Current status · Next action · Dependencies · Risks · Deliverables

## 운영

- 각 프로젝트는 `projects/<project-slug>.md` 하나로 관리한다 (`projects/_template.md` 사용).
- 전체 현황은 `projects/README.md`의 Project Board 표에 요약한다.
- 업데이트 시 변경 로그(날짜 + 한 줄)를 카드 하단에 남긴다.
- Next action은 항상 "다음 1–2시간 안에 할 수 있는 구체적 행동"으로 쓴다.
